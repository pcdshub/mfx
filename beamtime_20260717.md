## 1. Launch AMI and verify streaming

Once AMI is up, in the AMI GUI:

1. **Open** -> `xes_export_final2.fc` -> **Open**.

- **Read (data plane, host 172.21.152.83):** the flowchart outputs.

```bash
EPICS_PVA_ADDR_LIST=172.21.152.83 pvget -r value ami:ana:graph:data:goal
EPICS_PVA_ADDR_LIST=172.21.152.83 pvget -r value ami:ana:graph:data:centroids
EPICS_PVA_ADDR_LIST=172.21.152.83 pvget -r value ami:ana:graph:data:heartbeats
```

`goal` should be `[goal_x, goal_y]`, `centroids` should be `[cx, cy, rms]`, and
`heartbeats` should climb each time you re-run it.

- **Write (control plane, host 172.21.72.53):** set the Average2D window and apply.

```bash
EPICS_PVA_ADDR_LIST=172.21.72.53 pvget ami:ctrl:graph:Average2D.0:N     # read current window
EPICS_PVA_ADDR_LIST=172.21.72.53 pvput ami:ctrl:graph:Average2D.0:N 5   # set a shallow window
EPICS_PVA_ADDR_LIST=172.21.72.53 pvput ami:ctrl:graph:apply 1           # apply -> GUI rebuilds
```

Watch the GUI, `N` should flip to 5 and the graph should rebuild.

## 2. Connect the AMI class from Python

In hutch-python, import the alignment code and exercise both directions through the
`AMI` class.

```python
from mfx.optimize.vonhamos_align import (
    AMI, find_signal, align_yaw, optimize_focus,
    align_one_crystal, align_all_crystals,
)

ami = AMI()                 # connects over PVA, latches goal_x / goal_y
ami.goal_x, ami.goal_y      # the goal pixel
ami.centroid()              # (cx, cy), or None when the spot is off screen
ami.rms()                   # float, or inf when the spot is off screen

ami.set_averaging(100)      # deep window + apply 
ami.set_averaging(3)        # shallow window + apply
```

## 3. Single-crystal dry run

Only if the von Hamos is mounted and a crystal can produce signal. The code assumes
all crystals are parked out and there is no signal on the epix.

The functions switch the averaging window themselves: `find_signal` increases averaging to
detect a weak spot, then `align_yaw` / `optimize_focus` decrease averaging so
the centroid tracks the motor. You do not need to set averaging by hand between steps.

In hutch-python:

```python
spec.c1.rot.position                   # note where it starts
spec.c1.x.position

find_signal(spec.c1.rot, ami)          # sweeps rot until the spot appears
align_yaw(spec.c1.rot, ami)            # centers the spot on the goal (steers cy onto goal_y)
optimize_focus(spec.c1.x, ami)         # scans x, moves to minimum rms
```

Then the full chain with the manual checkpoint:

```python
align_one_crystal(spec.c1, ami)        # interactive=True by default
```

## 4. Align all crystals

Once the single-crystal chain looks good, run the full six. It aligns c1..c6 one at
a time, pausing after each for a manual fine-tune (Enter to save and continue), then
restores every crystal to its saved position.

```python
saved = align_all_crystals(spec, ami)  # interactive=True by default
saved                                  # {'c1': {...}, ..., 'c6': {...}} of aligned rot/x
```

Pass `interactive=False` to run straight through without the per-crystal pause.
